# Terrarium Leitstand

Web-App zur Überwachung von Kornnattern, Jemenchamäleon und Neukaledonischem Riesengecko (iPad quer, als Home-Bildschirm-App).

- Die App liegt im Wurzelordner (`index.html`) und wird über GitHub Pages ausgeliefert.
- Daten und Anmeldung: Supabase (`config.js` enthält nur URL und öffentlichen Schlüssel; die Daten schützt die Zeilensicherheit).
- Quellen, Tests und Datenbank-Skripte: Ordner `src/`.
